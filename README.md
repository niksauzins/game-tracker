# Game Tracker

A web application to track and manage your video games, log sessions, and rate finished games. Built with PHP, MySQL, and Tailwind CSS.

### Live App

You can access the live version of the application here: [tracker.nickroger.dev](https://tracker.nickroger.dev/)

### Features

- **User Authentication:** Secure registration and login.
- **Global Library & Personal Entries:** Add games from a global library to your entries, update statuses (Playing, Finished, Waitlist, Quit), and leave ratings.
- **Session Logging:** Track how much time you spend on each game by logging sessions.
- **Multi-language Support:** Toggle between English and Latvian.
- **Responsive Design:** Clean, Neo-Brutalist UI built with Tailwind CSS that works on both desktop and mobile.

### How to Setup

1. Clone or download this repository to your local server environment (e.g., `htdocs` folder in XAMPP).
2. Open `phpMyAdmin`, and import the database.sql file to create the database and tables.
3. Open `config/db.php` and update the database credentials (host, db name, user, password) to match your database.
4. Start your servers, and open the project in your browser.

# Spēļu Izsekotājs

Tīmekļa lietojumprogramma, kas ļauj sekot līdzi savām videospēlēm, pārvaldīt tās, reģistrēt spēļu sesijas un novērtēt pabeigtās spēles. Izstrādāta, izmantojot PHP, MySQL un Tailwind CSS.

### Tiešsaistes vietne

Lietojumprogrammas tiešsaistes versija ir pieejama šeit: [tracker.nickroger.dev](https://tracker.nickroger.dev/)

### Funkcijas

- **Lietotāju autentifikācija:** Droša reģistrācija un pieteikšanās.
- **Kopējā bibliotēka un personīgie ieraksti:** pievienojiet spēles no kopējās bibliotēkas saviem ierakstiem, atjauniniet statusus (Spēlē, Gaidāmās, Pabeigtas, Atmesta) un atstājiet vērtējumus.
- **Sesiju reģistrēšana:** uzskaitiet, cik daudz laika pavadāt katrā spēlē ar sesijām.
- **Daudzvalodu atbalsts:** Pārslēdzieties starp angļu un latviešu valodām.
- **Responsīvs dizains:** Neobrutālisma stila lietotāja saskarne, izstrādāta ar Tailwind CSS, kas darbojas gan datorā, gan mobilajās ierīcēs.

### Kā uzstādīt

1. Klonējiet vai lejupielādējiet šo repozitoriju savā lokālajā servera vidē (piem., `htdocs` mapē XAMPP).
2. Atveriet `phpMyAdmin` un importējiet database.sql failu, lai izveidotu datu bāzi un tabulas.
3. Atveriet `config/db.php` un atjauniniet datu bāzes autentifikācijas datus (hosts, datu bāzes nosaukums, lietotājs, parole), lai tie atbilstu jūsu datu bāzei.
4. Ieslēdziet savus serverus un atveriet projektu savā pārlūkprogrammā.
